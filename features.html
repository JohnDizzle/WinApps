Get started

  1. Let WinApps discover your installed applications. Use Refresh applications after installing or removing apps.
  2. On the homepage, scroll through running-app cards with the mouse wheel, swipe, or arrow buttons. Click a card linked to your installed library to open its overview, or use its switch button to bring the app’s window forward.
  3. Search the library by name or choose a letter to select an app. The rail reveals the selected app and its available files. Use Back or Clear selection to return home.
  4. Check the live resource footprint, then choose the Application, Package, or Files card to explore details below. Use the tabs for other available sections.
  5. To edit a supported setting, close the target application, change the value, and click Save. Reopen the target app to check the result.
  6. Open Settings to choose your theme and backdrop, or revisit Features, Privacy, and License.

See what’s open on your PC

The homepage carousel shows app icons, names, window titles, and RAM snapshots. WinApps checks for opened and closed windows about every two seconds. Newly detected apps appear first with a rainbow highlight that returns to normal after three seconds, or sooner when you click.

The carousel focuses on visible app windows, including minimized apps. WebView2 helpers, tool windows, overlays, and tray-only apps without a qualifying window are excluded. Opening a tray app’s main window can make it appear.

RAM values are snapshots, not continuously changing readings. New cards contribute to the total; Refresh activity takes a fresh snapshot of the open apps. Selecting a linked card carries its initial measurements into the overview.

Find your applications

Search a cached library of desktop and packaged applications, navigate by letter, and see application icons. Refresh the library when your installed apps change.

Follow live resource usage

A selected app’s resource footprint updates every five seconds with RAM, CPU usage, process count, and thread count. Its icon, name, and status indicator keep the readings tied to the app you selected. CPU shows Sampling until enough readings are available. Returning home stops the selected app’s live sampling.

Review startup apps

See entries registered through Windows Run locations and startup folders, with enabled or disabled status when Windows provides it. Expand the list to inspect commands and shortcuts, refresh the entries, or open Windows startup settings to manage startup behavior.

Understand packages

Inspect MSIX identities, manifests, versions, declared capabilities, dependencies, and related resource packages. View available runtime and trust information with explanations of what can be determined.

Explore local files

Browse accessible Settings and LocalState files, inspect sizes and modification dates, preview supported JSON, XML, and text, or open a file with its default application.

Edit supported settings

Use typed controls for supported Windows ApplicationData scalar values. Changes require an explicit Save and include type validation and stale-value detection. Close the target app first; it may overwrite settings when it exits.

Manage and launch

Switch to an open app, launch packaged apps, request administrator launch when supported, open Windows app-management settings, and uninstall a selected package after confirmation. For a running selected app, Terminate lets you request termination after confirmation. Unsaved work may be lost; when several matching processes are listed, the action applies to those processes.

Make it comfortable

Choose light or dark theme and Mica, Acrylic, or Mica Alt backdrops. Retry or restart after display errors, with technical details available when needed.

Know the current limits

Resource readings match executable paths to an app’s installation folder. Shared folders may include other apps, and helpers outside that folder may be missed. RAM is the current working set; adding working sets can count shared memory more than once. CPU is a percentage of total processor capacity. Multiple app instances may appear as separate process cards.

Startup discovery covers Run registrations and startup folders; packaged startup tasks, services, and scheduled tasks are not included. Some windows and process details may be inaccessible.

Registry hive discovery and SQLite file identification are available. Registry hive decoding and database table browsing are not currently supported. WinApps does not decrypt secrets or retrieve PasswordVault entries. Only accessible data and supported setting types can be inspected or edited.
