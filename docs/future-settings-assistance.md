# Future settings assistance

Saved from the product discussion on October 7, 2026. This is a future idea, not part of the current implementation.

Keep the package inspector and settings editor deterministic and usable without AI. Show actual keys, stored types, values, property-group explanations, and relevant Microsoft documentation.

Explore an optional user-invoked “Ask Copilot” action or a separately downloaded local LLM to explain property groups and help manage apps and their settings. Decide how context is selected and shared before implementing this. Distinguish explanations from proposed changes and preserve the existing typed settings editor and explicit Save action.

The current first step is three package-property layouts (Grid, Rows, Widgets), authored explanations, and Microsoft Learn links. No AI integration or model download is included.
